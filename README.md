## ⚙️ How to Run

### 🐧 Linux / macOS

```bash
g++ -std=c++17 filename.cpp -o output
./output
```

### 🪟 Windows (Command Prompt / PowerShell)

```bash
g++ -std=c++17 filename.cpp -o output.exe
.\output.exe
```

### 💡 Prerequisites

- **G++ compiler** (MinGW for Windows, or GCC on Linux/macOS)
- Any code editor — [VS Code](https://code.visualstudio.com/) recommended with the C/C++ extension
